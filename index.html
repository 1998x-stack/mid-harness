Three New Subsystems

Built on top of tiny-harness's core loop, mid-harness adds three extensibility layers.

⟐

Hook System

12 lifecycle hook points with 4 types: guard (abort), pre (modify), post (observe), wrap (replace). Run user hooks before skill hooks, with priority ordering and FIFO tiebreaker.

⇌

MCP Integration

Connect to external tool servers via Model Context Protocol. stdio and HTTP transports. Tools auto-registered as proxy handlers. Agent-owned lifecycle with ref-counting.

◆

Progressive Skills

Skills as directories with skill.md (YAML frontmatter + markdown), references/, scripts/, and assets/. Backward compatible with tiny-harness register(agent) pattern.

Install & Run

One dependency (httpx). Python 3.11+. Installs in seconds.

Install & run
# Install mid-harness
pip install mid-harness

# Run one-shot prompt
export DEEPSEEK_API_KEY="sk-..."
mid-harness "Create hello.py" --model deepseek-chat

# Interactive session with hooks
mid-harness --skills files,shell --tui
Python API — Agent with hooks and skills
from mid_harness import Agent, Prompt, Config
import asyncio, os

agent = Agent(
    prompt=Prompt("You are helpful."),
    config=Config(model="deepseek-chat",
        api_key=os.environ["DEEPSEEK_API_KEY"],
        workspace="."),
)

# Register lifecycle hooks
agent.hook("tool:pre_execute",
    lambda ctx: ctx.abort("blocked"),
    hook_type="guard", priority=100)
agent.hook("tool:post_execute",
    lambda ctx: print(ctx.data["result"]))

# Load skills
agent.load_skill("files")

result = asyncio.run(agent.run("Say hello"))

Component Architecture

mid-harness adds HookSystem, MCPManager, and ProgressiveSkillLoader to tiny-harness's core.

Package layout
mid_harness/
├── __init__.py          # Public API: Agent, HookSystem, HookContext, ToolDef
├── _hooks.py            # HookSystem — 12 lifecycle hook points
├── _core.py             # Agent — session, lifecycle, hook/unhook API
├── _loop.py             # AgentLoop — while-loop with hook injection
├── _tools.py            # ToolRegistry — collision detection, reserved names
├── _llm.py              # LLM providers (Anthropic, OpenAI, DeepSeek)
├── _mcp.py              # (Wave 2) MCPManager — server lifecycle
├── _skills.py           # (Wave 3) ProgressiveSkillLoader
├── cli.py / tui.py       # CLI one-shot + REPL + Rich TUI
├── skills/               # Built-in skills (files, shell, search)
└── tools/                # Tool handlers

12 Active Hook Points

Intercept, modify, or observe agent operations at these lifecycle events.

✓agent:init · post · fires once on first run()
✓session:start · post · fires once per session
✓skill:load · post · after skill registered
✓loop:start · pre/post · before first iteration
✓loop:iteration · pre/post · each iteration
✓loop:complete · post · final answer ready
✓llm:pre_call · pre · before API call
✓llm:post_call · post · after API call
✓llm:error · post · on API error
✓tool:pre_execute · guard/pre · before tool runs
✓tool:post_execute · post · after tool result
✓tool:error · post · on tool failure
